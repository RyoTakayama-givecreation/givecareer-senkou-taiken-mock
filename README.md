# Give Career 選考体験ページの画面シミュレーション

ローカルで起動する：

```sh
bash start.sh
```

ブラウザーで `http://127.0.0.1:8766/` を開く。インストールやビルドは不要。`index.html` を直接開いても表示できる。

ヘッダー・右サイドバー・フッター・CSS・画像は、既存の試作（`../prototype-givecareer-kuchikomi/`）と同じ共通パーツを使っている。本文だけを、今回の「選考体験」の設計に作り直した。

## ページ構成（ページごとに別のHTML）

| ページ | ファイル | 内容 |
|---|---|---|
| 一覧 | `index.html` | 選考体験の一覧。`index.html?r=0〜3` で立場ごとに絞り込み（0=入社、1=内定後に辞退、2=選考途中で辞退、3=面接で不合格） |
| 個別 | `story-1.html`〜`story-4.html` | 一人分のストーリー（章ごとにぼかし／会員表示） |
| 投稿 | `post.html` | 投稿フォーム。ステップごとに `#step-1`〜 のURLが付く。完了は `#done` |

- どのページも、ブラウザの「戻る」「進む」が普通に効く。絞り込みの状態は、一覧のURLに残る。
- 投稿フォームは、ステップを進めるたびに履歴が積まれる。戻るで前のステップに戻り、入力内容は残る。
- 「会員として表示」の状態と、投稿フォームの入力内容は、ブラウザのタブの中（sessionStorage）に保持される。タブを閉じると初期状態に戻る。
- ページ間のリンクは相対パス（`story-1.html` など）。そのままGitHub PagesやCloudflare Pagesなど、静的ホスティングに置ける。

```
index.html / story-*.html / post.html
assets/
  senkou.css   このプロトタイプ用のCSS
  data.js      項目と、仮の体験談データ
  app.js       画面の描画と操作
  reference/   現行ページの共通パーツ（CSS・画像・フォント）
```

## 元にしている設計

- 項目と、立場ごとの出し分けは、[選考体験項目表_立場別.xlsx](../選考体験項目表_立場別.xlsx) と同じデータから作っている。個別ページの章の並びと、投稿フォームの質問は、この表の内容そのもの。
- ストーリーの並び: 誰の話か → 動き出すまで → 探す・出会う → 応募する → 選考 → 結果 → 内定・決断 → 退職 → 入社後 → 締め。

## 試せる操作

- **一覧**: 立場での絞り込み。カードの見出しと属性は公開、本文はぼかし。
- **個別ページ**: 章ごとにぼかし表示。「会員として表示する」で全文を表示。立場によって載る章が変わる（例: 退職・入社後は入社した人のみ）。各面接は折りたたみ、年収は3点を1か所に並べて表示、併願先は一覧表示。同じ前職の人の体験談へのリンクもある。
- **投稿フォーム**: 最初に「選考結果」と「在職中か離職済みか」を聞き、以降の質問を出し分ける。面接は追加・削除できる。最後に、運営（AI）が付ける想定の見出し例を表示。
- 緑の「追加項目」バッジは、新しく追加した項目。

## 画面上のデータ

企業名・ロゴ・サイドバーは現行ページに合わせた。**体験談の内容、年収、件数は仮データ**。入力内容は外部へ送信されない。デモのため、必須の項目が未入力でも先へ進める。

## 作り直す場合

`index.html` などのページと `assets/app.js`・`assets/data.js`・`assets/senkou.css` は、スクリプトで生成した。項目表を変えた場合は、再生成が必要。
